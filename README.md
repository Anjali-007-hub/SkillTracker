SkillTracker 🎯

SkillTracker is a student skill tracking and learning analysis web application designed to help students manage and monitor their learning journey.

📌 About the Project

SkillTracker allows students to keep track of their technical skills, courses, goals, achievements, and overall learning progress in one place.

It also provides skill analysis, career-based skill gap identification, and a suggested learning roadmap based on the selected career goal.

✨ Features

- 💻 **Skill Tracking** – Add and manage technical skills with progress levels.
- 📚 **Course Tracking** – Track currently learning courses and their progress.
- 🎯 **Goal Management** – Create and manage learning and career goals.
- 🏆 **Achievements** – Store projects, certificates, and other achievements.
- 📊 **Progress Overview** – View overall learning progress.
- 🤖 **Skill Analysis** – Identify strongest and weakest skills based on progress.
- 🔍 **Skill Gap Analysis** – Compare current skills with skills required for selected careers.
- 🗺️ **Learning Roadmap** – Get a suggested learning path based on skill gaps.
- 🕒 **Recent Activity** – Track recent actions performed in the application.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- 🔎 **Search** – Search skills, courses, goals, and achievements.
- 💾 **Local Storage** – Data is stored locally in the browser.
